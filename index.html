Learn cmux by doing

cmux is a native macOS terminal built on Ghostty for running several coding agents side by side. This course takes about three hours in total, and almost all of it happens inside cmux itself.

How the academy works

1. Watch

The slide deck covers each module in 5 to 10 minutes. Press S for speaker view, ? for slide shortcuts.

2. Do

Small tasks, each with exact steps and a way to know it worked. Tick them off as you go.

3. Drill

Flashcards for shortcuts and commands, with spaced repetition by hand: the ones you miss come back.

4. Track and read

The spreadsheet holds confidence ratings and notes. The reading list points at the official docs.

Tip: view this inside cmux

Serve the folder and open it in a browser split, so the lesson and the practice sit side by side:

cd ~/Developer/study/terminal/cmux-academy
python3 -m http.server 8000
# in another pane:
cmux browser open http://localhost:8000

The slides load reveal.js from a CDN, so they need a network connection.

Based on the cmux docs and cmux --help for cmux 0.64.x. Shortcuts and commands change between releases, so check cmux docs shortcuts if something differs.
